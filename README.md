# acelexia

Acelexia is a voice-first adventure game that helps dyslexic children in Hong Kong (K3 to P6) practise 中, ENG and MATH. Players defeat bosses by reading words out loud, collect stars, and build their own adventurer.

Data & privacy
1. Collected for the game
• Username and a scrambled (hashed + salted) password — we never store the real password.
• Grade, avatar gender (only used to choose the avatar body), avatar items.
• Tower progress, stars, items, EXP, revision bank, daily streak and badges.
• Settings: text size, time limit, language.

2. Research input data
• The Input Data page records answers, correct/incorrect and time taken, with a random data ID.
• No name or account is attached. Only the admin can view it.

3. Collected by the hosting platform (Lovable)
• Basic hosting logs (such as request times and errors) kept by the platform to run the website.
• Question generation sends only the grade, subject and level — never the child's name or answers.

4. Cache & on-device data
• Login session, settings and progress copy are kept in the browser so the game works offline.
• Game graphics are downloaded and cached for offline play.
• Pressing Log out in Settings clears the session on this device.

5. Speech
• Speech is turned into text by the browser's built-in speech service. Acelexia never records or saves audio.

6. Security measures
• Account and progress tables are locked; only the game server can read or write them.
• Admin tools need the admin password.
• Input is checked on both the device and the server.

How your child's answers guide their practice
Two signals per answer. Every answer records whether it was right and how long it took. Slow-but-correct and fast-but-wrong tell us different things.
Spotting the gap. Answers are grouped by subject (中, ENG, MATH), topic and question type, such as look-alike characters (形近字), spelling or word problems.
Recent mistakes count more. Newer errors weigh more than old ones, so the plan follows how your child is doing now.
Focus on what matters most. The few topics causing most mistakes become the Re-quiz plan, and missed questions go to the Revision bank.
Back into play. These topics return as short practice rounds, so improvement happens inside the game.
Only answers and timings are used. Voice is processed on the device and never saved.
